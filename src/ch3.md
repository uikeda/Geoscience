| 海水の水温と塩分のグラフを何というか | T−S図 |
| 風浪とは何か | 風の力を直接受けてできる波 |
| うねりとは何か | 風浪が強風域から離れたり、風が弱まったりした後に残る、波の形の整った規則的な波 |
| 表面波とは何か | 深い海の海面の波のように、水深に比べて波長が十分に短い波 |
| 表面波の速さを表す式は？ | v = gT/2π = √(gL/2π)<br>（g：重力加速度、T：周期、L：波長） |
| 長波とは何か | 浅い海の波や津波のように、水深に比べて波長が十分に長い波 |
| 長波の速さを表す式は？ | v = √(gh)<br>（g：重力加速度、h：海の深さ） |
| 津波とは何か | 海底で大規模な隆起や沈降が急に起こり、海底から海面までの海水全体が動いてできる、周期が数十分、波長が数百kmもある巨大な波。深い海を伝わるときでも長波としてふるまう |
| 海流とは何か | 海洋表層での、ほぼ一定方向の海水の流れ |
| エクマン吹送流とは何か | 風に引きずられた海面付近の海水の流れが、転向力によって北半球では風の進む方向の右側（南半球では左側）にそれ、深くなるにつれてさらに右にそれていく流れ |
| エクマン輸送の特徴 | 風による海面付近の海水全体の流れで、風向に対して北半球では直角右向き、南半球では直角左向きになる |
| 地衡流とは何か | 圧力傾度力と転向力がつり合った状態で、海水面の高いほうを右に見ながら（北半球）等高線と平行に流れる海水の流れ |
| 海洋の中央部分の水面が高くなる理由 | エクマン輸送によって、北半球では貿易風帯の海水は北へ、偏西風帯の海水は南へ運ばれる。そのため、貿易風と偏西風に挟まれた海域で海水面が1〜2m程度高くなる |
| 西岸強化の仕組み | 海流にはたらく転向力は高緯度ほど大きい。そのため北半球では、西岸で北向きの海流に伴って時計回りの流れが生じ、北向きの海流が強められる。一方、東岸では南向きの海流に伴って反時計回りの流れが生じ、南向きの海流が弱められる。その結果、環流の西側に強い流れが現れる |
| 熱塩循環とは何か | 水温や塩分の違いによる海水の密度差で起こる、海洋の鉛直方向の流れ。高緯度の低温で密度の大きい表層の海水が深部へ沈み込み、海底を赤道方向へ流れ、それまで深層にあった海水が押し出されて上昇する |
| 深層循環とは何か | 北大西洋北部や南極付近から沈み込み、全地球の深層を巡る海水の大循環。1000〜2000年かけて循環する |
| 潮汐とは何か | 1日に1〜2回ずつくり返す、周期的な海水面の昇降 |
| 起潮力とは何か | 月や太陽の引力などによって海水が動き、潮汐を起こす力（潮汐力） |
| 月による起潮力と太陽による起潮力はどちらが大きいか | 月（太陽による起潮力の約2倍） |
| 高潮の発生過程 | 台風や温帯低気圧が通過するとき、気圧の低下で海面が吸い上げられ、強風で海水が吹き寄せられて起こる。大潮の満潮時に起こると、遠浅の海や陸側に入り込んだ湾で大きな被害が出やすい |
| テレコネクションとは何か | 離れた場所の気象が連動していること |
| エルニーニョ現象の発生過程 | 平常時は東よりの貿易風によって、暖水層が赤道太平洋の西部に吹き寄せられている。何らかの原因で貿易風が弱まると、赤道太平洋の中〜東部の暖水層が厚くなり、冷水の湧昇も弱まる。その結果、赤道太平洋東部の海水温が平常時より高くなる。活発な対流の領域も中〜東部に移るため、貿易風の弱い状態が続き、エルニーニョ現象も続く |
| ラニーニャ現象の発生過程 | 貿易風が平年より強くなって暖水層がさらに西部に吹き寄せられ、冷水の湧昇も強まる。その結果、赤道太平洋の中〜東部の海水温が平年より低くなる |
| エルニーニョ現象が起こると日本の気候はどうなるか | 夏は北太平洋高気圧が弱くなり、梅雨明けが遅れたり、夏の平均気温が下がったりする傾向がある。冬は季節風が平年より弱くなり、気温が高くなることが多い |
| 南太平洋の東西における海面気圧は一方が低く一方が高いが、これを何というか | 南方振動 |
| これらの大気と海洋の現象をまとめて何というか | エルニーニョ・南方振動（ENSO） |
| 黒潮や湾流の周辺で海洋から大気への熱輸送が大きい理由 | 海面水温のほうが大気の温度より高いため。熱帯から来る海流の水温が高いうえ、冬は西にある大陸から吹き出す季節風によって、この海域の大気が冷たくなる |
| 北極振動とは何か | 北半球に見られる半球規模の大気の変動。北極の上空の気圧が平年より低いときは中緯度の気圧が高くなり、反対に北極の上空の気圧が高いときは中緯度の気圧が低くなる |
| 北極振動が正であるとはどういうことか | 北極の上空の気圧が平年より低く、中緯度の気圧が高い状態。偏西風が強く、蛇行が小さくなり、日本付近は暖冬になる傾向がある |
| 都市気候とは何か | 人口が集中し、地表が舗装されて草や木が少なくなった都市に生まれる、都市特有の気候 |
| 都市部の気温が郊外より高くなる現象を何というか | ヒートアイランド現象 |
| 都市部で汚染物質が拡散されず留まる理由 | 郊外では夜間の放射冷却でできる逆転層が地表まで達するが、都市部は気温が高いため、逆転層が上空にできる。都市部は逆転層の下の暖かい空気にドーム状に覆われ、その空気が閉じ込められるため、汚染物質が拡散されない |
| オゾンホールの発生過程を説明せよ | フロンを起源とする塩素分子が、冬の南極上空で形成される極成層圏雲の表面で生成・蓄積され、春になると太陽光で分解されて塩素原子となり、オゾンを分解することでオゾンホールが発生する |
