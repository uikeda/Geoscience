| 付加体の形成メカニズムについて説明せよ | 海のプレートの表面には、海嶺でできた玄武岩、チャートなどの遠洋深海の堆積物、海溝に沈み込む直前にたまった陸から来た粗い砕屑物が重なっている（海洋プレート層序）。これらが海溝の地下にできる断層群によって海のプレートから次々にはがされ、陸のプレートの底へ順に押し付けられて付け加わる。そのため付加体では、一連の地層が逆断層でくり返し積み重なり、下ほど新しい関係になる |
| 大陸地殻の生成メカニズムについて説明せよ | 海嶺でできた玄武岩質の岩石は、熱水活動で変質して含水鉱物を多く含むようになる。これが海溝で沈み込むと、地下深くで高い圧力によって分解し、水を放出する。水によってマントルの岩石の融点が下がり、玄武岩質マグマができる。このマグマが上昇し、地下でゆっくり冷えて斑れい岩の下部地殻をつくる。この地殻がさらに部分溶融し、結晶分化作用をくり返すと流紋岩質マグマができ、冷えて固まって大陸地殻の主体である花こう岩になる |
| 変成作用とは何か | 地下の岩石が高い温度や圧力のもとに長く置かれると、鉱物が固体のまま化学組成の一部や結晶構造を変え、別の鉱物に変わって（再結晶）、別の岩石になる作用 |
| 広域変成作用とは | 造山帯で地殻に圧縮の力がはたらき、地殻の内部に広い範囲で温度や圧力の分布が周囲と異なる場所ができて起こる変成作用 |

| 低温高圧型変成岩の成因は | 冷たい岩石が沈み込み境界の深いところにもち込まれ、周りから温められる前に高い圧力を受けてできる |
| 高温低圧型変成岩の成因は | より陸側の地下で火成活動が起き、マグマが大量に上昇して周りの温度が高くなることでできる |
| 片岩の特徴は | 比較的小さな板状や柱状の鉱物の結晶が一方向に並び、片理という組織が発達している。そのため多くの平行な面で割れやすい。褶曲した構造がよく見られる |
| 片麻岩の特徴は | 比較的大きな長石や石英などの無色鉱物と、黒雲母などの有色鉱物が一方向に並んで縞模様をつくる。鉱物の組み合わせは花こう岩と同じだが、鉱物が縞状に分布している点が異なる |
| 古い時代の広域変成帯を調べると何が分かるか | 当時その付近にプレートの収束する境界があったこと。弧−海溝系などの地下の様子を推定できる |
| 接触変成作用とは | 高温のマグマが地殻に入り込み、マグマに接した岩石がその熱によって、幅数十〜数百mの範囲で受ける変成作用 |
